# C Programming Practice

This repository contains my C programming practice programs as I learn programming fundamentals and develop my problem-solving skills.

## Topics Covered
- Basic C syntax
- Conditional statements
- Loops
- Fibonacci series
- File handling

## Repository Structure
- `basics/` – Basic programs and conditional statements
- `loops/` – Loop-based programs
- `file-handling/` – File handling practice

## How to Run

Compile using GCC:

```bash
gcc program.c -o program
```

Run on Windows:

```bash
program.exe
```

Run on Linux/macOS:

```bash
./program
```
